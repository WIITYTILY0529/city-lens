# 도시결 · City Lens

공개 사이트: https://wiitytily0529.github.io/city-lens/

main 브랜치에 변경 사항을 올리면 GitHub Actions가 dist 폴더를 GitHub Pages에 자동 배포합니다.

228개 지역에서 연령 구성, 자연경관, 브랜드 매장 수가 비슷한 도시를 탐색하는 정적 웹사이트입니다.

## 사용하기

도시를 검색하고 세 기준을 선택·해제하면 유사 도시 TOP 10, 특성 공간 산점도, 레이더 차트와 원래 수치 비교가 갱신됩니다. 순위에서 도시를 선택하면 비교 대상이 바뀝니다. 로그인이나 서버 API가 필요하지 않습니다.

## 실행

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 http://localhost:4173 으로 접속합니다. dist 전체를 정적 호스팅에 배포할 수 있습니다.

## 분석 방법

- 연령 6개 비중을 각각 표준화합니다. 산·해수욕장·브랜드 수는 log1p 후 표준화합니다.
- 연령의 각 축에 1/√6, 자연의 각 축에 1/√2를 곱해 세 기준의 전체 분산을 동일하게 맞춥니다.
- 브랜드는 스타벅스와 올리브영의 총매장 수이며 인구로 나누지 않습니다.
- 선택한 그룹 수로 나눈 제곱거리의 제곱근 d를 100/(1+d)로 환산합니다. 이 점수는 확률이 아닙니다.
- KMeans: K=2~10, n_init=50, seed=20260915. 상세 탐색 목적에 따라 추천 후보는 K≥3입니다.
- 지역 80%를 15회 재표집하고 전처리와 모델을 재학습해 전체 지역 예측의 ARI를 측정합니다. 최소 군집 8곳, 평균 ARI≥0.8 후보 중 최고 실루엣에서 0.02 이내인 가장 작은 K를 고릅니다.
- 모든 기준 선택 시 권장 K=3. 선택 조합마다 별도 모델을 사용합니다. 유사도 순위는 군집 소속으로 제한하지 않습니다.
- 산점도는 PCA 특성 공간이며 지리적 위치가 아닙니다. 레이더 축은 228개 지역 내 백분위입니다.

## 데이터와 한계

공개 파일 dist/data.json에는 지역별 가공 수치와 모델 결과만 포함합니다. 원본 매장 목록·주소는 포함하지 않습니다. 기존 정리 기준에 따라 일반구를 시로 통합하고 인천 중구·동구를 공통 권역으로 묶었습니다.

연령은 2026년 6월, 브랜드는 2026년 6월 상가 파일, 산은 2026-09-10 목록, 해수욕장은 2025년 목록을 사용했습니다. 첫 연령 컬럼 명칭은 원문의 ‘20대_이하’를 유지합니다. 산·해수욕장 0은 자연경관 자체가 없다는 뜻이 아닙니다. 두 브랜드의 상호 식별 기록은 공식 전체 점포 수나 도시화의 완전한 측정치가 아닙니다. 매장 총수에는 지역 규모의 영향도 포함됩니다. 소비 성향이나 인과관계를 증명하는 분석은 아닙니다.

## 재현

Python에 numpy, pandas, scipy, scikit-learn을 설치한 후 기존 분석의 지역별_원시피처.csv를 입력합니다.

```sh
python3 generate_data.py --input /path/to/지역별_원시피처.csv
```

입력 컬럼: SIDO_NM, CCG_NM, 인구합계, 20대_이하_비중, 20대_비중, 30대_비중, 40대_비중, 50대_비중, 60대_이상_비중, 자료내_산수, 자료내_해수욕장수, 지정브랜드_매장수, 스타벅스, 올리브영.

현재 배포된 결과는 dist/data.json에 보존됩니다. 라이브러리 버전이 달라지면 재학습 결과가 조금 달라질 수 있습니다.
